# wikiwatch
Weekly snapshot of the English Wikipedia page "Wikipedia:Signs of AI writing"
(https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) and the diffs between
revisions, fetched automatically through the MediaWiki API. The page text and diffs are
unmodified output from Wikipedia. Authors are listed in the page history:
https://en.wikipedia.org/w/index.php?title=Wikipedia:Signs_of_AI_writing&action=history
